# NAQAA

Bilingual Arduino environmental monitoring dashboard.

Website: https://ryanw506.github.io/NAQAA./

Open in desktop Chrome or Edge, connect the Arduino by USB, close Serial Monitor and select the matching baud rate. Readings come from your connected device. History is recorded locally in your browser for 24 hours while connected; USB data is not shared remotely.
